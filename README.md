## 🚀 איך להעלות ל-NotebookLM

### שיטה 1: העלאת קובץ Markdown (מומלץ!)

זו הדרך הכי מהירה - NotebookLM יקלוט את כל 32 הסרטונים בבת אחת!

1. **פתח NotebookLM:**
   - לך ל- https://notebooklm.google.com/
   - התחבר עם חשבון Google שלך

2. **צור מחברת חדשה:**
   - לחץ על **"Create new notebook"** (יצירת מחברת חדשה)
   - תן לה שם: **"Chair Tai Chi Video Library"**

3. **העלה את קובץ ה-Markdown:**
   - לחץ על **"+ Sources"** (הוסף מקורות)
   - בחר **"Upload"** (העלאה)
   - בחר את הקובץ: `chair-tai-chi-videos.md`
   - המתן שהקובץ יעלה (כ-10 שניות)

4. **✅ זהו! כל 32 הסרטונים עכשיו במחברת!**

---

### שיטה 2: העלאת URLs בודדים

אם אתה רוצה לבחור סרטונים ספציפיים:

1. פתח את `chair-tai-chi-videos.md`
2. גלול ל**"Quick Links for Easy Copying"** (בסוף הקובץ)
3. העתק URLs של הסרטונים שאתה רוצה
4. ב-NotebookLM:
   - לחץ **"+ Sources"** → **"Web URL"**
   - הדבק URL
   - לחץ **"Import"**
   - חזור על זה לכל סרטון
